# codewars

My solutions of Codewars kata in Python: 13 short scripts.

A small project of my own from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2023 (first commit on 7 February 2023, last commit on 9 February 2023).

## Contents

- `spin_words.py`: reverses every word that has 5 or more letters.
- `descending_order.py`, `unique_number.py`, `nar_number.py`, `sum_of_two_lowest_positive_integers.py`: number kata.
- `vowel_count.py`: the "who likes it" kata (function `likes`).
- `human_redable_time.py`, `mexican_wave.py`, `strip.py`, `List Filtering.py`, `safda.py`, `main.py`: other kata and experiments.
- `sum of digits.py`: it stops with an error when run.
- `.idea/`: PyCharm project files.

## Running

```
python3 spin_words.py
```

Result on 26 November 2026 (Python 3.14): `Hey wollef sroirraw`.
